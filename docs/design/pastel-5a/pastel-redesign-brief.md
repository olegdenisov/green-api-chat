**Цель документа.** Дать Claude Code контекст, чтобы он **сначала составил план изменений** (по файлам, этапами, с оценкой рисков) и согласовал его, а потом реализовывал.

Визуальный макет: вариант **5a** — скриншот `handoff/pastel-5a-reference.png` (светлая и тёмная темы, компоненты, иконки, принципы). Используй его для сверки после каждого этапа; при расхождении приоритет у значений из брифа.

> Инструкция для Claude Code: прочитай бриф, изучи указанные файлы, затем выдай план в формате из раздела 9. Код не меняй, пока план не утверждён.

## 1. Суть изменений

1. Новая палитра: пастельные фоны и один насыщенный фиолетовый акцент `#6C5CE7`.
2. Новая форма: «плавающие» карточки (сайдбар и чат — отдельные белые блоки на лавандовом фоне), крупные радиусы, аватары-скруглённые квадраты, почти без теней.
3. Единый набор линейных иконок (stroke 1.8, round) вместо текущих из `src/shared/ui/icons.tsx`.
4. Обновлённые компоненты: поиск, чипы-фильтры, бейдж непрочитанных, индикатор онлайна, композер-«пилюля», статусы доставки.
5. Светлая и тёмная темы из одной системы токенов.

**Обязательно (scope A)** — только визуал: пункты 1–3, 5 и рестайл существующих элементов.
**Опционально (scope B)** — новые UI-функции из макета (раздел 7). Для каждой отдельно проверить, поддерживает ли их GREEN-API и текущая модель данных. Без подтверждения не делать.

## 3. Форма и размеры

- **Раскладка:** корневой контейнер фон `--ga-app-bg`, `padding: 12px`, `gap: 12px`; сайдбар и чат — карточки `--ga-surface`, `border-radius: 22px`. На мобильном (<768px, текущий брейкпоинт) — без внешнего отступа и радиуса, карточка на весь экран.
- **Радиусы:** карточки 22 · пузыри 20 (хвост 6) · аватар в списке 16 (46px), в шапке 14 (42px) · поля и кнопки 14 · иконки-кнопки 12 · чипы и бейджи 999. В теме: `defaultRadius` = 14px.
- **Тени:** только у композера (`0 2px 10px rgba(60,50,120,.08)` + 1px ring `--ga-border`). Остальное — без теней.
- **Фокус:** `box-shadow: 0 0 0 2px primary, 0 0 0 5px --ga-bubble-out-bg`.
- **Типографика:** системный стек без изменений. Заголовок сайдбара — «Чаты», 18/650; имя в шапке чата — 16/650; имя в строке списка — 15/600; превью — 13.5; мета — 11.5–12. Бренд «GREEN-API chat» остаётся на логин-странице и в `<title>`.

## 6. Статусы доставки

Показывать иконкой в мете пузыря: `clock` (pending), `check` (sent, цвет meta), `check-check` (read/delivered, primary), failed — текст «Не отправлено» + pill «Повторить».

## 7. Опциональные функции из макета (scope B) — только оценить

Для каждой в плане: есть ли данные в API или локально, трудоёмкость, рекомендация «делать / не делать».

1. **Поиск / фильтр по списку чатов** — локальный фильтр по имени и номеру.
2. **Чипы «Все / Непрочитанные / Группы»** — нужны флаги unread и group у чата.
3. **Бейдж непрочитанных** — счётчик входящих после последнего открытия чата, хранение локально.
4. **Статус «в сети»** — вероятно недоступен через GREEN-API; скорее не делать.
5. **Кнопки вложения и эмодзи** — сейчас только текст; скорее не делать или показывать disabled.
6. **Поиск по переписке** (иконка в шапке) — скорее не делать.

## 8. Критерии приёмки

- Обе темы соответствуют макету 5a (цвета, радиусы, иконки).
- Контраст всего текста ≥ 4.5:1. Пастельные цвета не используются как цвет текста на белом. На primary в dark — тёмный текст.
- Нет захардкоженных цветов вне `theme.ts` и CSS-переменных (кроме `favicon.svg` и `index.html`).
- Клавиатурная навигация и фокус-кольца сохранены, `aria-label` у иконок-кнопок на месте.
- Мобильная раскладка работает (список ↔ чат).
- `make check` зелёный, тесты обновлены (аватар, тема, пузырь).
