- маленькие сфокусированные изменения
- **CRITICAL: каждая задача с кодом включает новые/обновлённые тесты**
- **CRITICAL: начиная с Task 3, каждая задача заканчивается зелёным `pnpm check`**
- **CRITICAL: обновлять этот план при изменении скоупа**
- **CRITICAL: версии, CLI-флаги и конфиги create-vite, Vite, Vitest, Mantine, Reatom,
  oxlint, oxfmt, steiger сверять по актуальной документации/`--help`/npm, а не по памяти.**
  Если API отличается от описанного здесь — следовать документации и отметить ⚠️ в плане.

  появится) и посторонних файлов.

- **unit/component tests**: Vitest + Testing Library (jsdom). Общий `test/render.tsx`
  оборачивает компонент в Mantine- и Reatom-провайдеры со свежим контекстом на каждый тест —
  им пользуются все последующие этапы.
- **e2e**: нет (не требуется заданием).

## Solution Overview

- Скаффолд `create-vite` (шаблон `react-ts`) генерируется во временную папку, в проект
  копируется явный список файлов — так не задеваются `.git`, `docs/`, `AGENTS.md`.
- Инструменты качества ставятся сразу после Vite, чтобы все следующие решения (особенно
  размещение файлов по FSD) сразу проверялись steiger и линтером.
- Тестовая инфраструктура — вне `src/`: `vitest.setup.ts` и `test/` в корне. Steiger
  проверяет только `src/`, а слой `shared` не создаётся ради тестов.
- FSD-скелет минимальный: `src/app` (провайдеры, стили, `app.tsx`) и `src/pages/home`
  (заглушка). `src/app/index.ts` не создаём — `src/main.tsx` импортирует `@/app/app`.
- Провайдеры: `reatomContext.Provider` → `MantineProvider` → `Notifications`.
- Makefile — тонкая обёртка над pnpm-скриптами.

## Technical Details

### Скрипты `package.json`

| скрипт         | команда (флаги сверить по докам)                                  |
| -------------- | ----------------------------------------------------------------- |
| `dev`          | `vite`                                                            |
| `build`        | `tsc -b && vite build`                                            |
| `preview`      | `vite preview`                                                    |
| `test`         | `vitest run`                                                      |
| `test:watch`   | `vitest`                                                          |
| `lint`         | `oxlint --deny-warnings`                                          |
| `format`       | `oxfmt`                                                           |
| `format:check` | `oxfmt --check`                                                   |
| `lint:fsd`     | `steiger ./src`                                                   |
| `typecheck`    | `tsc -b`                                                          |
| `check`        | `lint` → `format:check` → `lint:fsd` → `typecheck` → `test`       |
| `clean`        | удалить `dist`, `coverage`, `node_modules/.vite`                  |
